# Protocolo de navegador M2.2.1

Estado: **pendiente**. Las pruebas automatizadas no acreditan QA visual. Preparar `npm run verify`, servir `dist` con `npm run preview` y abrir `/demo` en un navegador funcional. Registrar versión del navegador, viewport, preferencias, hash de fuentes y capturas/vídeo. La copia recibida no tiene repositorio Git reconocible.

| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Continuidad     | Ampliar cada foto con clic/touch; cerrar con botón. Grabar ambas direcciones.                                                                            | La misma fotografía viaja entre origen y destino, con oscurecimiento progresivo, sin panel abrupto ni salto del recorte/hover al proxy. Medir CLS/LCP y fluidez/consumo en un móvil real. Una captura estática o el build no prueban continuidad, foco real ni rendimiento. Sin estas observaciones no se puntúan timing, jerarquía visual o performance con la rúbrica de Motion Director.
