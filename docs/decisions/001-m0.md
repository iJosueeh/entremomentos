# ADR 001 — Base M0 feature-first

Estado: implementación preparada; resolución npm y validación integrada pendientes.

## Decisión

Astro estático con integración oficial React para una sola isla; Tailwind 4 mediante `@tailwindcss/vite`, sin integración antigua de Tailwind 3. TypeScript strict oficial extendido, ESLint flat config, Prettier Astro y Vitest node. No se necesita SSR desplegado ni adaptador.

Usar carpetas feature-first solicitadas, sin migración ceremonial a todas las capas FSD. Tipos inferidos en schemas; crear componentes UI compartidos o lib solo cuando exista reutilización. No crear public/images sin imágenes reales.

GSAP se carga desde un efecto React y mantiene un contexto propio. La preferencia de movimiento usa un listener nativo con limpieza explícita; permite también descartar imports pendientes. No añadir @gsap/react para un único efecto acotado.

## Inspección y versiones

Entorno: Fedora 44, Node 24.22.1, npm 12.2.2, Git y Python disponibles. Home contiene un directorio .git que no es un repositorio válido; no se modifica. No se encontró EntreMomentos en Projects o Documentos (búsqueda hasta profundidad 4). Proyecto nuevo aislado en ~/Projects/entremomentos. No se inicializa Git ni se crean commits.

Se consultaron releases oficiales y documentación el 2026-11-15. Astro 7.4.11, integración React 7.1.9, React 19.3, GSAP 3.15.1 y Tailwind 4.3.3 son las bases consultadas; los rangos permiten correcciones compatibles. Herramientas auxiliares usan versiones estables observadas en publicaciones o caché. La caché no acredita que una versión sea la última. No se afirma compatibilidad integrada hasta resolver npm y ejecutar gates. No existe lockfile porque no pudo completarse la instalación.

## Skills

Inventariadas ~/.agents/skills y ~/.claude/skills; catálogo de Codex también disponible. No se encontraron skills locales porque no había proyecto. No se instalaron skills.

Leídas y aplicadas: `ponytail` (alcance mínimo completo), `feature-slicing` (imports y propiedad), `gsap` (contexto y limpieza), `ui-ux-pro-max` (contraste, foco, targets, responsive y movimiento reducido). Se ejecutó su búsqueda de sistema visual: sus propuestas genéricas Swiss/Outfit/Work Sans se descartaron en favor de la identidad editorial solicitada.

Revisadas sin activar su flujo completo: `design-taste-frontend` impone ausencia de lavanda, escenas y un kit de página completa que contradicen el brief y M0. `impeccable` ofrece un proceso más amplio de identidad; no se necesitó para esta base técnica. No se usan sus gates ni se afirma haberlos pasado. Prevalecen alcance, paleta y stack del usuario.

`safe-refactor` no aplica al ser proyecto nuevo. `systematic-debugging` no fue necesaria: el bloqueo de instalación se identifica explícitamente como red/caché. `find-skills` no fue necesaria tras el inventario local. Hay skills de motion y frontend adicionales; no se activan indiscriminadamente. No se delegó trabajo a otros agentes.
